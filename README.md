# esp32-morse-communicator
Want a simpe esp32 project? Here you can make a simple communicator for you and your friend! you just need 2 esp32s, 2 screens, and 2 buttons!

🛠️ Dual-ESP32 Morse Code Communicator: Complete Setup GuideThis guide walks you through building a peer-to-peer wireless Morse code messaging system using two ESP32 DevKit V1 boards, I2C OLED displays, and tactile push buttons.Step 1: Gather Your ComponentsTo build one complete node (you will need two for bidirectional communication), collect the following hardware:1x ESP32 DevKit V1 (30-pin or 38-pin version)1x I2C OLED Display (128x64 pixels, SSD1306 driver)1x Tactile Push Button (4-pin)1x Half-size BreadboardJumper wires (Male-to-Male and Male-to-Female)Micro-USB / USB-C cable for programmingStep 2: Wire the HardwareBoth ESP32 boards share the exact same wiring layout. Connect your components according to the table below:ComponentComponent PinESP32 GPIO PinDescriptionOLED DisplayVCC3.3VPower supplyOLED DisplayGNDGNDCommon groundOLED DisplaySCLGPIO 19I2C ClockOLED DisplaySDAGPIO 22I2C DataPush ButtonPin 1 / Side AGPIO 21Input signal pinPush ButtonPin 2 / Side BGNDPulls pin LOW when pressedBreadboard Tip: Make sure your 4-pin push button spans across the center divide (trench) of the breadboard to avoid short-circuiting the internal pins.Step 3: Install Arduino IDE & LibrariesOpen the Arduino IDE on your computer.Ensure you have the ESP32 board package installed via Tools > Board > Board Manager.Go to Sketch > Include Library > Manage Libraries... and search for and install:Adafruit GFX Library (by Adafruit)Adafruit SSD1306 (by Adafruit)Step 4: Find Your ESP32 MAC AddressesBecause ESP-NOW requires specific peer routing, you need the unique MAC address of both ESP32 boards.Upload this short sketch to each board and open the Serial Monitor (115200 baud) to find their MAC addresses:C++#include <WiFi.h>

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  Serial.print("MAC Address: ");
  Serial.println(WiFi.macAddress());
}

void loop() {}
Example addresses from your build:ESP32 #1: 70:4B:CA:04:72:5CESP32 #2: 70:4B:CA:82:C0:7CStep 5: Flash the CodeOpen your project files in Arduino IDE.In ESP32 #1's code, make sure the target receiver address is set to ESP32 #2's MAC address (0x70, 0x4B, 0xCA, 0x82, 0xC0, 0x7C).In ESP32 #2's code, make sure the target receiver address is set to ESP32 #1's MAC address (0x70, 0x4B, 0xCA, 0x04, 0x72, 0x5C).Select your correct COM port and board model, then flash the code to each respective board.Step 6: How to Operate the SystemIdle Screen & Cheat Sheet: When not typing, the OLED displays a gliding Morse code alphabet cheat sheet that auto-cycles every 2 seconds, alongside any recently received messages.Typing Letters:Quick tap (< 1 sec): Inputs a dot (.).Medium hold (1–5 sec): Inputs a dash (-).Letter timeout (1.2 sec silence): Automatically converts your dots and dashes into text characters.Sending Messages:Press and hold the button down for 5 seconds.The screen will flash "SENT!" for 2 seconds as confirmation before returning to the idle screen.Reading Incoming Messages:When a message arrives, the screen automatically switches to a dedicated view displaying your message in large font (or normal font if the message is extra long).
